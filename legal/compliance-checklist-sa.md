# South African compliance checklist

*Working checklist for importing and selling a food product in South Africa.
Sources in [`../research/sources.md`](../research/sources.md).*

> **This is a working document, not legal advice.** Before the first order ships,
> a food labelling consultant should review the artwork and a clearing agent
> should confirm the import file. Both are cheap. A detained container is not.

---

## 1. Import

| | Status |
| --- | --- |
| Register as an importer with SARS (customs code) | ☐ |
| Appoint a clearing agent | ☐ |
| Confirm tariff classification — **HS 1704** (sugar confectionery, not containing cocoa) | ☐ |
| Confirm whether a DALRRD import permit is required for this product | ☐ |
| Health / free sale certificate from the supplier | ☐ |
| Certificate of Analysis for each production batch | ☐ |
| Confirm Port Health inspection requirements at the port of entry | ☐ |

**Duties and taxes**

| | |
| --- | --- |
| Import duty | **25% of the FOB customs value** (HS 1704) |
| VAT on import | 15% of ATV = customs value + 10% uplift + non-rebated duty |
| Health Promotion Levy | **Does not apply.** The HPL covers sugary *beverages* only. |

Consignments are detained by SARS on arrival for inspection. **The importer
carries full responsibility for compliance** — the supplier's assurances are not
a defence.

## 2. Labelling — R146 of 2010

R146 prescribes minimum labelling requirements for all foodstuffs imported or
sold in South Africa. Every tin must carry:

| | Status |
| --- | --- |
| Product name and true description | ☐ |
| Net weight (35g) | ☐ |
| Full ingredient list, descending order by mass | ☐ |
| **Sweeteners declared specifically by name** (R733/2012) | ☐ |
| Nutritional information table | ☐ |
| Allergen declaration | ☐ |
| **Country of origin** | ☐ |
| Name and SA address of importer/distributor | ☐ |
| Batch identification | ☐ |
| Best-before date | ☐ |
| Barcode registered with **GS1 South Africa** | ☐ |

### The "sugar-free" claim

- Threshold under R146/2010: **≤0.5g sugar per 100g**
- The claim requires **laboratory verification**, and nutrient claims must be
  **re-tested every three years**
- Budget for this. It is in the setup costs at R32,000 for lab analysis,
  nutritional panel and label review.

### Origin claims — the one to get right

R146 prohibits labelling that misleads as to origin. **The product is made in
China. The company is South African.** The Irish design reference must therefore
be styling and story, never a provenance claim. No "Product of Ireland", no
"Irish recipe", no shamrock-plus-Gaelic lockup that functions as an
origin mark. Detail in `brand/brand-brief-pj-offner.md` §5 and
`research/04-global-opportunity.md` §6.

### No medicinal claims

A strong menthol mint sits uncomfortably close to a throat lozenge — note that
Fisherman's Friend is stocked in the *sore throat* aisle at Checkers. **Any
medicinal, health or therapeutic claim moves the product into a different
regulatory category** with far heavier requirements. Say the mint is strong. Never
say it does anything.

## 3. Draft R3337 — front-of-pack warning labels

Not yet law; R146 of 2010 remains current. Draft R3337 proposes mandatory
front-of-pack warning logos for products high in sugar, sodium or saturated fat,
**and for products containing artificial sweeteners.**

**This has a direct design consequence and a direct formulation consequence:**

1. If we use an artificial sweetener (aspartame, acesulfame-K), we should expect
   to need a warning logo on the front of the tin when R3337 lands.
2. Polyols such as xylitol and natural sweeteners such as steviol glycosides are
   the safer route on this point.
3. **Leave physical space in the tin artwork for a front-of-pack logo** even if
   we do not need one at launch. Re-tooling tin artwork is expensive.

Tracked as R-04 in `ops/risk-register.md`.

## 4. Company and tax

| | Status |
| --- | --- |
| Company registered with CIPC | ☐ |
| SARS income tax registration | ☐ |
| **VAT registration** — compulsory above R1m turnover in 12 months; register voluntarily from day one to reclaim import VAT | ☐ |
| PAYE / UIF / SDL once employing | ☐ |
| Customs importer code | ☐ |
| Shareholders agreement | ☐ |
| B-BBEE affidavit or certificate (needed by many retail and corporate customers) | ☐ |

**Register for VAT immediately.** Import VAT is 15% of the ATV on every
container. Unregistered, that is a cost. Registered, it is a claim. On the first
order alone it is tens of thousands of rand of cashflow.

## 5. Food safety

| | Status |
| --- | --- |
| Supplier certifications: HACCP / ISO 22000 / BRC | ☐ |
| Food-grade certification for the tin's interior lacquer | ☐ |
| Certificate of Acceptability for any premises where food is stored or handled | ☐ |
| Product liability insurance | ☐ |
| Traceability and batch recall procedure documented | ☐ |

A recall procedure is not bureaucracy. It is what a national retailer asks for
before listing, and what a licensee's due diligence will look for.

## 6. Order of operations

1. Company, SARS, VAT, importer code
2. **Trademark filed** — before any artwork is published anywhere
3. Supplier certifications obtained and verified
4. Sweetener decided (regulatory + brand decision, see `product/product-spec.md` §5)
5. Label drafted → **reviewed by a compliance consultant** → artwork finalised
6. Lab analysis for the sugar-free claim
7. GS1 barcodes registered
8. Clearing agent briefed, import file assembled
9. First PO placed
